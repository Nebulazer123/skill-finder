# Diligence Statement

In creating Skill Finder, I collaborated with AI systems to plan, draft, test, and refine the skill instructions, examples, validation checks, and public-facing project materials.

AI assistance contributed to brainstorming the workflow, structuring the search and ranking rules, drafting documentation, running local validation, evaluating the skill with test scenarios, iterating on recommendation quality and practical efficiency, and creating the selected README logo image. I reviewed and directed the work, made the final decisions about what to include, and take responsibility for the published content.

This disclosure is included so readers can understand the human intent behind the project, where AI contributed, and where users should still apply their own review.

This repository is intentionally limited to public-safe project materials. Private planning notes, internal validation packets, local paths, credentials, and personal workspace files were excluded from the public package.

Skill Finder is intended for people who use AI agents regularly and want a better way to discover current third-party skills, tools, MCP servers, workflows, packages, and capability stacks. It is provided as a workflow aid: users should review candidate tools, install commands, licenses, account or credential requirements, and safety boundaries before taking action. Generated logo imagery is project art, not trademark-cleared final identity work.

For a fuller explanation of how the skill was built, how the project scores evolved, and how the human role was separated from AI assistance, see [HOW_THIS_SKILL_WAS_BUILT.md](HOW_THIS_SKILL_WAS_BUILT.md).
