# Example Request: Large Repo Search

```text
I have a large messy repo and the assistant keeps wasting context opening files one at a time. I need a local capability that helps a coding agent understand definitions, callers, endpoints, config links, and risky changes without uploading my code. Find the best installable option.
```

Skill Finder should search across code search, semantic search, structural search, graph/indexing tools, MCP servers, and adjacent workflows. It should inspect finalist files, compare source routes, and recommend no more than five options.
